# 课程内容审校记录

## 本轮发现

- 旧版正文由同一个六段模板生成，同一章案例会在每个小节重复出现。
- 每章只有一段 Python，却被复制给该章所有课；部分代码引用未定义的 `df`、`X` 或 `y`。
- 练习题由固定十条模板替换名词生成，题干和解析不能检验具体知识。
- 旧审计只统计数量，无法发现重复、空公式、案例错配和无效代码。

## 已完成修订

- 保留 24 章、60 单元、180 课、1800 题及全部课时 ID。
- 将课程拆为 `lib/content/chapter-01.ts` 至 `chapter-24.ts` 共 24 个显式内容文件。
- 每课改为课时专属定义、分析逻辑、适用边界、单一完整案例和报告模板。
- 专业版与宝宝巴士版仍逐节对应，正文不再出现完全重复段落。
- Python 实验由 180 个削减为 10 个；均包含完整数据生成、依赖导入、随机种子、预期输出和诊断。
- 没有代码实验的课程不显示代码板块，也不生成代码题。
- 质性课程使用研究立场、语境、编码轨迹、备忘录、负面案例、伦理和反身性语言，不套用量化术语。
- 重新编写练习结构，简单、中等、困难配比保持 4/4/2，解析按题型给出不同步骤和错误说明。

## 自动审计标准

- 数量、ID、课时顺序、单元和主题覆盖完整。
- 课内及全站专业版/宝宝版正文无完全重复段落。
- 不允许旧模板措辞、重复题干、重复解题步骤和空白双版本段落。
- 案例全文只在完整例题区域出现，不再追加到六个正文小节。
- 有公式必须有符号与条件说明；无公式不得显示空公式框。
- 有代码必须同时包含目的、数据、代码、预期输出、解释和诊断；无代码不得出现代码题。
- 博士阶段每课必须具有开放研究任务、评分量表、示例标准与常见缺陷。

## 验证结果

- `npx tsc --noEmit`：通过。

- 10 个 Python 实验：均通过 Python AST 语法检查。
- GitHub Pages 环境生产构建：所有五个构建阶段与静态预渲染完成。Windows 下 vinext 在构建完成后的进程关闭阶段仍会触发上游 libuv 断言；Linux GitHub Actions 不受该关闭问题影响。
