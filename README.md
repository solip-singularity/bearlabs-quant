# 贝尔实验室 · 量化研究学习站

由 Solips-Singularitat 创作的“社会科学方法学习站”，面向社会学、人类学、心理学及跨学科科研学习者，覆盖交互式概率统计与博士研究方法课程。

## 本地启动

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

启动后打开终端显示的本地地址，通常为 `http://localhost:5173/`。

## 检查与构建

```bash
node scripts/content-audit.mjs
npm run build
```

内容审计不仅检查 3 个学习阶段、24 章、60 单元、180 个课时和 1800 道分级练习，也会阻止重复正文、重复题干、旧模板措辞、空公式、无数据代码及不完整解析进入构建。学习进度保存在浏览器本地存储中，不会上传到服务器。

## 主要功能

- 3 阶段、24 章、60 单元、180 节独立课程
- 专业版 / 宝宝巴士版逐节对应讲解
- 每课包含用途、条件、公式或分析流程、方法比较、完整例题、案例与报告模板
- 正态分布与因果图互动实验，六条研究导向学习路径
- 每课 10 道简单、中等、困难练习，共 1800 题及分层解析
- 仅在模拟、估计或诊断确有教学价值时出现的 Python 实验；其余课程使用手算、案例推演或方法核查
- 全文搜索、收藏、错题与本地学习进度
- 独立的“关于本站与作者”页面，以及中国美术学院网络社会研究所（INS）研究背景说明
